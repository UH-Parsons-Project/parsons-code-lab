After registering and logging in successfully, the user will be able to see all available task sets on their teacherdashboard. Here, the user is able to create a new task set, view the task sets they created or the ones shared with them by other teachers. The user is also able to browse the task database and custom tasks here, as well as create a completely new task to add to a task set.

The user can view statistics regarding each individual student in the task set as well as each task in the set by clicking on the desired task or student on the task set page. The user is also able to view the task database by clicking on the "Task Database" button on the navbar.
