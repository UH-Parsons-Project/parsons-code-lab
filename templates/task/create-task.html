Create a New Task

Write plain Python in the first editor and any Python test code in the second editor. You can use assert, loops, helper functions, and multiple test cases.

Step-by-Step Guide: Function Unit Tests

  1. Write the Task Function

    In the Task Code editor, write a Python function that defines the task students need to solve.

  2. Create Test Cases

    In the Task Tests editor, write tests that verify the function works correctly. Use assert statements for clear checks.

  3. Continue to Block Builder

    When ready, click "Continue To Block Builder" to arrange blocks and distractors. To create a faded editable block, type !BLANK (e.g. total = !BLANK).

Example Task: Format Names

Function that formats first and last names with title casing:

Task Code 
def sum(a, b):
    total = a + b
    return total
Task Tests 
assert sum(1, 5) == 6
assert sum(5, 5) == 10

Step-by-Step Guide: Console Output

  1. Write Python Print Code

    In the Task Code editor, write Python code that prints text using print(...) statements.

  2. Specify Expected Output

    In the Expected Output editor, write the exact text string that student code should output.

  3. Continue to Block Builder

    When ready, click "Continue To Block Builder" to set up scrambled code blocks and distractors for students.

Example Task: Hello Greeting

Function that prints a greeting for given targets:

Task Code 
def hello(target):
    print("Hello", target)
Function Calls (Optional) 
hello("Emily")
hello("Bob")
Expected Output 
Hello Emily
Hello Bob

Step-by-Step Guide: Order Only (Conceptual)

  1. Write Scrambled Lines / Steps

    In the Task Code editor, write each line or conceptual step on a separate line in the correct order.

  2. No Code Execution or Tests Required

    Order-only tasks grade students purely on placing the blocks in the correct sequence without executing code.

  3. Continue to Block Builder

    Click "Continue To Block Builder" to finalize the block sequence and add optional distractor blocks.

Example Task: Pie

Order of making a pie:

Task Code (Lines) 
Buy all ingredients
Bake a pie
Eat the pie
